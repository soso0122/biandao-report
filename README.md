# Eagle素材库数据解析工具

一个简单的Python工具，用于将Eagle素材库页面复制的数据转换为CSV格式。

## 功能特点

- ✅ 直接复制粘贴，无需手动整理
- ✅ 自动去重
- ✅ 提取文件命名、上传人、状态三个关键字段
- ✅ 生成Excel可直接打开的CSV文件
- ✅ 无需安装额外依赖

## 使用方法

### 1. 在Eagle页面复制数据

1. 打开Eagle素材库页面（https://eagle.zhenguanyu.com/new/material-management/internal-library）
2. 筛选出你需要的素材
3. 点击"全选当前页"或使用快捷键 `Ctrl+A`（Windows）/ `Cmd+A`（Mac）
4. 复制：`Ctrl+C`（Windows）/ `Cmd+C`（Mac）

### 2. 运行解析工具

**方法一：双击运行**
- 直接双击 `parse_eagle.py` 文件

**方法二：终端运行**
```bash
cd ~/Desktop/eagle-data-parser
python3 parse_eagle.py
```

### 3. 粘贴数据

1. 在终端中粘贴刚才复制的内容
2. 粘贴完成后：
   - **Mac**: 按 `Ctrl+D`
   - **Windows**: 按 `Ctrl+Z` 然后回车

### 4. 获取结果

- 工具会自动生成CSV文件，文件名格式：`Eagle素材库_YYYYMMDD_HHMMSS.csv`
- 文件保存在当前目录
- 可以直接用Excel打开

## 输出格式

生成的CSV包含3列：

| 文件命名 | 上传人 | 状态 |
|---------|--------|------|
| 0603-9物-自产-自产主-李博-曲中雨-子衿-A6-B2-无-3 | jiazijinbj | 未同步 |
| 0526-199双科-自产-自产主-王晶-亿晨-子衿-A7-B1-有-4 | jiazijinbj | 未同步 |
| ... | ... | ... |

## 注意事项

1. 确保复制的是Eagle页面的完整内容
2. 工具会自动去除重复项
3. CSV使用UTF-8编码，Excel可直接打开
4. 每次运行会生成带时间戳的新文件，不会覆盖旧文件

## 系统要求

- Python 3.6 或更高版本
- 无需安装额外的第三方库

## 问题排查

### 提示"未能解析出有效数据"

- 检查复制的内容是否完整
- 确保复制的是Eagle素材列表，不是其他页面
- 尝试重新复制并粘贴

### CSV文件中文乱码

- 使用Excel的"数据 -> 从文本/CSV"导入功能
- 或者用其他支持UTF-8的表格软件打开（如WPS、Google Sheets）
