新增素材监控名单追踪功能：

1. 新建 data/监控名单.csv（表头：素材id、素材名称、加入日期、备注），用户口头发名单，我负责写入和追加。
2. 修改 scripts/generate_report_daily_guide.py：
   - main() 加载监控名单（仿 load_label_map 模式），按素材id优先、名称（去"推送视频_"前缀）兜底匹配到 days_data 全部历史逐日数据。
   - 对每个监控素材计算周期数据：首投日、末投日、在投天数、停投次数(≥2天)、已停天数、当前状态（在投/已停N天/从未开投），以及累计消耗、点击率、转化数、转化率、高潜、深转率，和近14天逐日消耗+高潜轨迹。
   - HTML 在素材明细表上方新增「监控素材」表格卡片区块，独立于日期筛选（始终显示全周期），停投≥2天状态标红，近14天轨迹用 CSS 迷你柱状图（仿生命周期报告的 traj-bar）。
3. 名单中匹配不到或从未有消耗的素材显示「未开投/无数据」，不报错。
4. 用 1012 报告生成并 Playwright 验证（渲染、无 JS 错误），复制到本地发布仓库并推送 GitHub Pages；企微不发送。
5. 依赖：等用户发第一批监控名单后写入 CSV 并执行。
